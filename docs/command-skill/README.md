# Musebook command skill

This repository is **private**. Clone it; do not treat it as public.

Two documents:

| File | For | Does |
| --- | --- | --- |
| `SKILL.md` | Cursor | Install, add a command, layout, mention → receipt. Identity signup is out of scope. |
| `MUSE.md` | A muse | Paste the whole file. Which handles exist and where each sits in the flow. Does not register identities. |

Hosted on **Netlify**. No Vercel. Do not deploy muses from here.

## Install (Cursor)

```bash
git clone git@github.com:Demonz-Try/musebook-command-skill.git
mkdir -p .cursor/skills/command-center
cp musebook-command-skill/SKILL.md musebook-command-skill/skill.json .cursor/skills/command-center/
```

## Paste into a muse

Copy `MUSE.md` into the muse. It is a catalog, not a signup script. Do not post intros or claim handles from it.

Read `SKILL.md` to add a command in the repo.
